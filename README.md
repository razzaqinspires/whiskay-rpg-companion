# WHISKAY RPG Companion — Stage 17

Next.js / React Three Fiber browser RPG website. It is a separate project from the WhatsApp bot.

## Stage 17 changes
- Unified landing page and open-world entry; inventory remains available.
- Low-poly Dungeonia cave entrance at world coordinates `(14, -8)`; approach and press `E` to enter.
- One dungeon instance with 100 generated floors and scaling enemy stats / bosses every fifth floor.
- `/adventure` and `/dungeon` require a signed short-lived token generated by the WhatsApp bot's `.enterdungeon` command.
- A signed, access-checked API persists selected dungeon player updates to Supabase.

## Configure and run
1. Set `BOT_SYNC_TOKEN` (or `DUNGEON_SYNC_TOKEN`) to the same long random secret as the bot's `DUNGEON_SYNC_TOKEN`.
2. Set `SUPABASE_URL` and `SUPABASE_SERVICE_ROLE_KEY` on the server only.
3. Install dependencies with `npm ci`.
4. Run `npm run dev`; validate with `npm run verify:stage17` and the other `verify:*` scripts.

## Audit report and limitations
See [`docs/STAGE-17-AUDIT.md`](docs/STAGE-17-AUDIT.md). Client combat remains partly simulated. For production-grade anti-cheat and race-safe economy, move all reward/spend and combat mutations to atomic Supabase RPCs and validate access on every state-mutating route. Full Next.js production build and live database integration have not been run in this workspace.
